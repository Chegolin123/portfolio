Инженерная база и продуктовое мышление — от серверов до ИИ.

Студент 4 курса по специальности «веб-разработка». Fullstack-разработчик с практическим опытом работы с IT-инфраструктурой: администрирование серверов на дистрибутивах Linux, работа с различными СУБД, настройка IP-камер и систем видеонаблюдения.

ИИ-ассистент для Service Desk

На FastAPI + PostgreSQL: категоризация заявок и ответы по базе знаний через LLM. Управляющий интерфейс на React / Next.js.

02

Telegram Mini App для клиентов

Подача и отслеживание заявок, контроль статусов и SLA, взаимодействие с инженерами.

03

Чат-бот первой линии поддержки

На aiogram — снятие типовой нагрузки с инженеров, ответы по частым вопросам.

04

Аналитика инцидентов

Обработка логов Zabbix / PRTG через LLM для выявления аномалий и типовых причин.

05

Computer Vision для видеонаблюдения

Распознавание объектов и событий с IP-камер, аналитика по зонам и инцидентам.

06

Внутренние ассистенты для инженеров

Поддержка по регламентам, документации и конфигурациям.

07

Развёртывание локальных LLM в контуре клиента

Для конфиденциальности данных и работы в изолированных сетях — актуально для требований ФЗ-152.

Квалификация в области ИИ

Специализация — прикладная интеграция языковых моделей: подключение LLM через API (DeepSeek, OpenAI), промпт-инжиниринг, обработка структурированных ответов. Для задач класса ассистенты / чат-боты / RAG этого достаточно для полноценного продукта.

Глубокое обучение собственных моделей в круг задач не входит — используются готовые решения. Помимо облачных моделей, знаком с подходом к развёртыванию локальных LLM (Ollama, vLLM, llama.cpp) и открытыми моделями с поддержкой русского (Qwen, Saiga), готов взять эту задачу с перспективой дообучения под нужды компании.

Наряду с этим — уверенная инженерная база (серверы, Linux, БД, видеонаблюдение) и сильный frontend. Это позволяет не только подключить ИИ, но и довести его до продукта: интерфейс, бэкенд, деплой, сопровождение.
